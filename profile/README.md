## Boundry

**A small, deterministic kernel that admits or refuses AI-proposed actions, and leaves a record anyone can check offline.**

An AI, a person or a program may only *propose* an action. A kernel that contains no model admits or refuses it against declared rules, executes an admitted action from the same sealed bytes that were checked, and records every decision, refusals included, in a signed, hash-chained record that an independent verifier can check on your own machine.
